# Política de segurança

## Relato responsável

Não publique vulnerabilidades, credenciais ou dados pessoais em uma issue pública.
Entre em contato diretamente com o mantenedor do projeto e inclua:

- descrição do problema;
- impacto esperado;
- passos mínimos para reprodução;
- sugestão de correção, quando disponível.

## Segredos

Arquivos `.env`, senhas, tokens, chaves privadas e credenciais de banco nunca
devem ser incluídos no repositório. Caso uma credencial seja exposta, ela deve
ser revogada e substituída imediatamente, inclusive quando o commit for removido.
